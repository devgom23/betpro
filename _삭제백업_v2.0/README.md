# v2.0에서 지운 코드 백업

2026-08-23, 버전을 1.0 → 2.0으로 올리면서 **아무 데서도 쓰이지 않던 코드**를 지웠습니다.
지우기 전 원본을 여기에 그대로 남겨 둡니다. 이 폴더는 프로그램 동작과 아무 상관이 없어서
필요 없다고 판단되면 폴더째 지우셔도 됩니다.

## 무엇을 지웠나

| 파일 | 내용 |
|---|---|
| `removed_api_endpoints.py.txt` | 서버 기능 5개 — 화면에서 아무도 부르지 않던 것 |
| `removed_MatchDetailModal_functions.jsx.txt` | 상세보기 화면 함수 4개 (76줄) |
| `kr_crawler_zentoto_backup.py` | 예전 젠토토 크롤러 (와이즈토토로 교체하면서 안 쓰게 됨) |

### 지운 서버 기능 5개가 뭐였는지
- `POST /api/analyze` — 아무 배당이나 넣으면 26개 지표를 즉석에서 계산해 주던 기능.
  화면에 이 기능을 쓰는 버튼이 없습니다. (계산하는 엔진 자체는 그대로 살아 있습니다 —
  엑셀 업로드할 때 이 엔진이 돕니다.)
- `DELETE /api/bet_batches/{batch_id}` — 벳등록 한 묶음을 통째로 지우는 기능.
  지금은 베팅내역 화면의 "선택 삭제"를 쓰므로 안 불립니다.
- `POST /api/crawl/close`, `POST /api/crawl/kr/open`, `POST /api/crawl/kr/close`
  — 예전에 크롬 창을 띄워 놓고 긁던 시절의 "창 열기/닫기" 기능.
  와이즈토토로 바꾼 뒤로는 창 자체가 없어서 필요 없어졌습니다.

### 지운 상세보기 함수 4개가 뭐였는지
`sigBadge` / `sigFootText` / `sigFootClass` / `IndLevelsTable`.
예전 '종합 분석' 카드 4장(플핸무 확률·해외지표·국내지표·상대전적)을 화면에서 뺐을 때,
그리는 코드만 남겨 뒀던 것입니다. 그 카드를 다시 만들 때 참고하려면 이 파일을 보세요.
**백엔드 계산(`api/pick_ai.py`)은 지우지 않았습니다** — 지금도 그대로 계산되어 내려옵니다.
