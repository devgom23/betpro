# 예상점수 영역 백업 (2026-09-04 화면에서 제거)

상세보기 팝업 안 "확률 지표" 칸 아래 4단(경기지표·배당차·시스템판정·예상점수) 중
마지막 칸이었던 "예상점수" 표를 화면에서 뺐다. 계산 로직 파일(`web/src/utils/expectedScore.js`)은
다른 곳에서 쓰지 않는 채로 그대로 남겨 두었으니, 되살릴 때는 아래 3곳만 다시 붙이면 된다.

## 되살리는 방법
1. `web/src/utils/expectedScore.js` — 삭제 안 했음, 그대로 있음.
2. 아래 "① JSX 함수"를 `MatchDetailModal.jsx`의 `PickBand` 함수 바로 위에 다시 넣는다.
3. 아래 "② 렌더 호출"을 `PickBand`의 `pick-band-bottom-cols` div 안, `pick-band-sys` 다음에 다시 넣는다.
4. 아래 "③ CSS"를 `MatchDetailModal.css`에 다시 넣는다.
5. `.pick-band-bottom-cols`의 `grid-template-columns`를
   `max-content max-content 240px max-content`(4칸)로 되돌린다
   (지금은 예상점수 칸을 빼서 `max-content max-content 240px`(3칸)로 줄여 놓았다).

## ① JSX 함수 (MatchDetailModal.jsx)

```jsx
// 예상점수 — 시스템 판정이 낸 픽에 맞는 스코어 한 개를 초기/배변 두 시점으로.
// 두 줄 다 '그 시점에 등록된 배당 전부'(국배+해배)로 다시 만든다 — CLAUDE.md 4-1.
function ScoreTable({ row, pick }) {
  const cell = (final) => {
    const s = expectedScore(row, pick, final)
    if (!s) return <span className="dir-none">—</span>
    return (
      <b
        className="score-val"
        title={`${final ? '배변' : '초기'} 배당 기준 — ${s.markets === 2 ? '국배·해배 둘 다' : '한쪽 배당만'} 반영.`
          + `\n같은 배당대에서 '${pick}'의 배제(안 나온다고 본 결과)를 지킨 경기 `
          + `${s.n.toLocaleString()}건 중 이 스코어가 ${s.rate}%로 가장 많았습니다.`
          + '\n※ 스코어 맞히기는 원래 어렵습니다 — 아무것도 안 보고 1-1을 부르면 11.71%,'
          + ' 이 표대로 부르면 16.53%(6대리그 35,947경기).'}
      >
        {s.home}-{s.away}
      </b>
    )
  }
  return (
    <table className="detail-table sys-table score-table">
      <thead>
        <tr>
          <th className="row-label">예상점수</th>
          <th>홈-원정</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <td className="row-label">초기</td>
          <td>{cell(false)}</td>
        </tr>
        <tr>
          <td className="row-label">배변</td>
          <td>{cell(true)}</td>
        </tr>
      </tbody>
    </table>
  )
}
```

## ② 렌더 호출 (PickBand 안, pick-band-bottom-cols div)

```jsx
<div className="pick-band-score">
  <ScoreTable row={row} pick={pick} />
</div>
```

(`pick-band-sys` div 다음, `pick-band-bottom-cols`를 닫는 태그 앞에 넣는다.)

또한 `MatchDetailModal.jsx` 맨 위 import 목록에 아래 줄이 필요하다(이번엔 지우지 않고 그대로 뒀다):
```js
import { expectedScore } from '../../utils/expectedScore'
```
