# 패턴분석-02 — 플핸 확률 공식

사용자가 2026-10-09 저장을 지정했다("패턴분석-02 스킬 저장"). **"패턴분석-02"로 부르면 현재 계산 방식을 불러온다.**
패턴분석-01(접전형 + 마감 하락 패턴)과 달리 이건 **경기마다 확률 하나**를 내는 공식이고, 01은 이 공식의 근거(기존 점수 4점↑) 안에 들어 있다.
계수·근거·등급 경계를 바꾸거나 근거를 더하면 그건 '패턴분석-03'이다 — 요청이 있으면 새 번호로 만든다.
(분석 경위·실측: 메모리 `reference-plhan-unified-formula` · `reference-match-chip-audit` / 화면 규칙: CLAUDE.md 10-1·10-2장)

## 0. 시작할 때
- 모델 안내(CLAUDE.md 0장): 그냥 돌려 보여주기 → **Sonnet**으로 충분. 근거를 더하거나 공식을 고치기 → **Opus**.
- 아래를 실행하고 3의 형식으로 보고한다. 숫자는 스크립트 출력만 쓴다.

## 1. 실행 (읽기 전용 — 서버 불필요)
```
python .claude/skills/pattern-analysis-02/scripts/p02_run.py            # 저장된 공식·등급표(학습 파일 stats.json의 unified)
python .claude/skills/pattern-analysis-02/scripts/p02_run.py --round    # + 안 치른 경기의 플핸 확률 상위 15 (20~40초)
python .claude/skills/pattern-analysis-02/scripts/p02_run.py --retrain  # 최신 결과로 다시 학습(약 3분, data/master/plhan/ 갱신) 후 보여주기
```
- 학습·계산 본체는 `api/plhan_score.py`(`_train_unified`)이고 이 스크립트는 그걸 불러 쓴다. 학습 파일이 없으면 칩이 `—`로 뜬다.
- `--round` 목록은 기존 점수 4점↑ 근거를 0으로 둔다(학습 모델·표본 카드가 필요) — 정확한 값은 상세보기 칩에서 본다. 마감 배당을 킥오프 가까이 불러온 뒤 돌려야 의미가 있다.

## 2. 정의 (바꾸지 말 것)
`logit P = 절편 + 기울기·logit(시장이 본 플핸) + Σ 근거 계수`  (단통 플핸 = 무+역, 국내 초기 정배 기준, 핸무는 실패)

| 판 | 시장(출발점) | 근거 |
|---|---|---|
| 마감판 | 12사 평균 마감 `mb_L_pnw` → 없으면 Bet365 마감 → 국내 초기. 마감 배당이 있을 때 | 기존 점수 4점↑(패턴분석-01 + 동의 3개, 0~5점 중 4 이상) · 플축(P1∪P2∪P3, `api/axis_stats.py`) · 플핸85(해외 정배 2.40↑ · 해외 무 3.20 미만 · 해외 정역반전 · 홈기준 전적 우세가 언더독 쪽) |
| 초기판 | 12사 초기 + 국내 초기 | 플축(초기 배당신호만으로) — 최신배당 전에 '초기'를 붙여 보여준다(CLAUDE.md 4-1) |

- 계수 2026-10-09 학습: 마감판 −0.061 + 1.075·시장 + 0.797·4점↑ + 0.570·플축 + 0.152·플핸85 (규제 C=10, 15-16~26-27 전부).
- 등급: 75%↑ · 65~75% · 55~65% · 55% 미만. 시험은 18-19~이고 **시즌마다 그 앞 시즌(15-16~)만 배운 공식**으로 계산(미래를 안 본다).
- **첫맞대결은 뺐다** — 넣는 조건: ① 시험 오차↓ ② 시즌마다 계수 + ③ 65%↑ 경기 적중이 안 떨어짐. ①②는 통과, ③에서 70.8%→69.6%로 떨어져 제외(`_train_unified` 주석).
- 플축·국≠해(9월)는 '배변 판정 플핸무' 조건이 과거 시점 재현 불가라 공식 밖. 7레드(37경기)도 공식 밖.

## 3. 보고 형식
1. 학습 시각·경기 수, 두 판의 식(계수)
2. 등급표 — **기간(찾기 18-19 / 고르기 19-20~21-22 / 최근 5시즌 22-23~)마다 적중/경기** + 표 아래 기간 뜻 한 줄
3. (--round) 이번 회차 상위 경기와 근거
4. 정직하게: 마감 = 과거 최종 배당이라 몇 시간 전 배당으로도 같은지는 미검증 · 플축 규칙은 9월에 전 시즌을 보고 만든 것이라 안 본 시험 기간이 없다(세 기간 모두 +10%p↑로 버팀)
5. 마지막에 다음 행동(재학습·근거 추가 여부) 묻기

## 4. 2026-10-09 기준 결과 (저장 시점)
마감판 시험 16,530경기(9시즌): **75%↑ 81.4% (206/253)** — 찾기 7/8 · 고르기 63/79 · 최근 5시즌 136/166 / 65~75% 65.7% (348/530) / 55~65% 59.2% / 55% 미만 39.4%.
같은 기간 기존 4점↑는 적중률이 같고(82.6%) 경기 수는 절반(시즌당 15 vs 28). 초기판 75%↑ 75.2% (91/121) · 65~75% 74.3% (130/175).
