# 패턴분석-01 — 단통 플핸(무+역) 패턴

사용자가 2026-10-07에 저장을 지정했다: **"패턴분석-01로 부르면 현재 계산 방식을 불러온다."**
그래서 이 스킬은 **같은 식·같은 문턱값**으로 최신 데이터에 다시 돌리는 것이 일이다.
문턱값을 바꾸거나 조건을 더하면 그건 '패턴분석-02'다 — 바꾸자는 요청이 있으면 새 번호로 따로 만든다.
(분석 경위·실측 전부: 메모리 `reference-plhan-closing-drift-pattern`)

## 2. 정의 (바꾸지 말 것)
모든 값은 **정배 = 저장 RT의 기준(국내 초기 정배)** 관점. 확률은 배당에서 업체 몫(마진)을 뺀 값.

| 국내 접전형 | 국내 초기에서 역배 배당 ≤ 무 배당 × 0.876 (예: 무 3.20 → 역배 2.80 이하) | `k_dshare ≤ 0.467` |
| 하락(Bet365판) | 해외(Bet365=앱의 해외배당) 마감 정배확률 − 국내 초기 정배확률 | `x_ef_k_pf` |

## 3. 보고 형식 (CLAUDE.md 0-1장)
1. 등급표: 판·등급·경기·시즌당·찾기/고르기/확인·전체·리그 범위. **2026-10-07 기준값과 달라졌으면 그 차이를 먼저 말한다**
   (데이터가 늘어서인지, 계산이 깨져서인지 구분 — 결과 난 경기 수가 늘었는데 비율이 1~2%p 움직이는 건 정상).
2. 이번 시즌 결과 난 경기의 등급별 적중(표본이 작으면 작다고 말한다).
3. 이번 회차 목록: 등급 붙은 경기 + 국내 접전형(감시 대상). 'B기준·B12s기준' 배당을 같이 보여주고
   "킥오프 가까이 최신배당을 불러와 그 팀 마감 배당이 기준 이상이면 해당"이라고 쉬운 말로.
4. 늘 같이 말할 주의:
   - 단통 플핸 = 무+역. 핸무는 보험이 아니라 실패다(축 기준 — CLAUDE.md 5-1).
   - 모든 등급이 **마감 배당**을 쓴다. 과거 값은 킥오프 직전 최종값 — 몇 시간 전 배당으로도 같은지는 미검증(2026-10-07 기준).
   - 손으로 붙인 추가 조건(폼·순위·오버언더 등)은 과적합이었다(앞 시즌으로 고르면 확인 63.6%) — 새로 붙이자고 하면 정직한 재측정부터.
